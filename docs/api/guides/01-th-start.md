# 🇹🇭 เริ่มต้นใช้งาน

API ของเว็บไซต์สมัครงาน SHD — หน้าเว็บสาธารณะ หน้า admin และระบบอื่นใช้ API ชุดเดียวกันนี้

## ที่อยู่

```
https://<โดเมน>/api/v1/…
```

ทุก endpoint อยู่ใต้ `/api/v1` และตอบเป็น JSON (ยกเว้น export CSV และดาวน์โหลดไฟล์)

## สองกลุ่ม

| กลุ่ม                      | ใครใช้                    | ต้อง login ไหม                                                               |
| -------------------------- | ------------------------- | ---------------------------------------------------------------------------- |
| **Jobs**, **Site content** | หน้าเว็บสาธารณะ, ผู้สมัคร | ไม่ต้อง                                                                      |
| **Admin · …**              | ทีม HR                    | ต้อง (SSO — ยังไม่เปิด: ใน development เปิดให้ใช้ได้, ใน production ตอบ 503) |

## สมัครงาน

`POST /jobs/{code}/applications` ส่งเป็น `multipart/form-data`:

- ข้อมูลข้อความเป็น field ปกติ — การศึกษา ประสบการณ์ และทักษะส่งเป็น **JSON string**
- เรซูเม่ (บังคับ) PDF/DOC/DOCX ไม่เกิน 5 MB · ไฟล์แนบอื่นไม่เกิน 5 ไฟล์ ไฟล์ละ 10 MB
- ชนิดไฟล์ตรวจจาก**เนื้อไฟล์จริง** ไม่ใช่นามสกุล
- จำกัด 5 ใบ / 10 นาที / IP — เกินแล้วได้ `429` พร้อม `Retry-After`

## Error

ทุก error ตอบรูปเดียวกัน:

```json
{ "error": { "code": "bad_request", "message": "…", "issues": [{ "path": "email", "message": "…" }] } }
```

`issues` มีเฉพาะ `400` ที่มาจากการตรวจข้อมูล — บอกว่าช่องไหนผิดอะไร ครบทุกช่องในครั้งเดียว

| Status | code                | ความหมาย                                   |
| ------ | ------------------- | ------------------------------------------ |
| 400    | `bad_request`       | ข้อมูลไม่ถูกต้อง                           |
| 401    | `unauthorized`      | ยังไม่ login                               |
| 403    | `forbidden`         | login แล้วแต่ไม่มีสิทธิ์                   |
| 404    | `not_found`         | ไม่มี (รวมถึงตำแหน่งที่ยังเป็นร่าง/ปิดรับ) |
| 409    | `conflict`          | ซ้ำ เช่น รหัสตำแหน่งนี้มีแล้ว              |
| 429    | `too_many_requests` | ส่งถี่เกินไป                               |
| 503    | `unavailable`       | ระบบที่ต้องพึ่งยังไม่พร้อม                 |

ทุก response มี header `x-request-id` — แจ้งเลขนี้มาเวลารายงานปัญหา
